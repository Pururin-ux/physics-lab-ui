# PhysicsLab UI prototype

Older interface prototype for PhysicsLab. The current application and active development live in the main `PhysicsLab` repository.

This repository is kept as a UI reference and contains an earlier Next.js/React implementation.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Radix UI components

## Run locally

```bash
pnpm install
pnpm dev
```
